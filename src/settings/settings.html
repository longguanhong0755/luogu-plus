Luogu++ 设置

配色

改动即时生效，无需重启

主题色

挑一个颜色，洛谷页面与应用外壳的所有色块都会跟着它走——卡片底、页面底、 文字、边框按不同比例朝它混色，所以任何色相都能自动适配，明暗两套都成立。 选「中性」则回到纯黑白。

浓度越高，色块越"实"；0 等于关掉主题色。文字始终按最低比例混，保证读得清。

玻璃皮肤

液态玻璃 = 半透明底 + 背景折射 + 顶部镜面高光 + 边缘光 + 柔和投影，外壳与洛谷页面一起换。配合壁纸效果最好。

浓度 0 最透（几乎只剩折射与高光），100 最实。

形状与线条

圆角 R 同时作用于外壳与洛谷页面卡片；玻璃风格建议 12–20。只改应用皮肤，不动洛谷自己的数据与功能。

窗口外观

只缩放应用外壳（标签栏 / 工具行），不影响洛谷页面。

开启时 /ide 编辑器页完全不套主题与滤镜，避免代码配色被改坏。

标签栏形态

开启：标签竖排在左侧（可折叠成窄条，悬停浮出完整列表），左侧图标坞撤下， 栏最下方改为固定的洛谷快捷入口（首页 / 题库 / 题单 / 比赛 / 记录 / 讨论 / 文章 / 私信 / 通知 / 我的主页）。
关闭：回到顶部标签条 + 左侧图标坞。

侧栏位置

右侧模式：垂直标签栏贴窗口右缘（Edge 也支持左右）。展开时拖侧栏边缘可调宽度（160~400px）。

关闭重复标签时保留

「整理标签页 → 关闭重复标签」的保留策略。判定忽略 #锚点、末尾斜杠、www. 与 http(s) 差异； 钉住、本地页与分屏中的标签不会被关。整理后可随时「撤销」。

自定义 CSS

改动即时生效，不需要重启。写坏了把文本框清空即可恢复。洛谷页慎用 * 这类全局选择器——可能把页面功能样式一起覆盖。

侧坞图标

坞的位置

链接写全网址（如 https://www.luogu.com.cn/discuss，站内跳转）或站外网址（新标签打开）， 也兼容洛谷路径（/problem/list）、地址栏映射词、@home（应用首页）/ @ide（IDE）。改动即时生效。

背景壁纸

播放模式

可一次导入多张组成壁纸集合；0 分钟 = 不自动换，随机 / 顺序模式下启动时也会自动换一张。导入时内容相同的文件会自动去重。

支持图片与视频（mp4 / webm）。壁纸在「亮色 / 暗色 / 液态玻璃」下可见；「原色」模式完全不干预洛谷页面。

页面整理

藏掉广告位、首页轮播与侧栏商业推广卡。

公告条、推荐模块、页脚弹窗、顶部装饰一并收掉。

搜索引擎

地址栏搜索回退、首页搜索框、地址栏联想里的「搜索」行都用这一家。洛谷引擎走站内导航（仍锁洛谷域）； 其余引擎在新标签里打开，不套洛谷主题。%s 是关键词占位符（自定义模板必须含它）。

效率功能

兜底地址栏（题号 / UID / 关键词 / 映射词）之外，列表页顶部再加一个就地筛选框。

题目列表的原生筛选行增强：关键词输入即筛当前列表（不必回车），行尾显示本页条数。

鼠标移到洛谷的代码块上，右上角出现「复制」。题解、样例、他人代码都能一键拿走。

把洛谷的难度色阶压成灰阶，配合黑白线条风使用。

下次启动时把上次的全部标签页原样开回来（含当前活动标签）。

后台闲置超过这时长的标签自动卸载（标签位保留、标题带月牙标，点回去才重新加载），省内存。0 = 不自动休眠。活动标签、拼合组、钉住的、正在放声音的不会睡；右键标签也可手动「休眠此标签页」。

非活动标签恢复 Chromium 定时器节流（活动、分屏、正在出声的标签不受影响），后台网页不再全速跑定时器，多标签时更省 CPU。

系统可用内存不足（约 1.5GB 或 15% 以下）时，把最久未用的后台标签提前休眠。

首页

首页顶部加一条：你的头像 + 问候 + 每天换一句的吐槽。

把每日签到的运势改成「§ 大吉 §」，宜/忌两列一并换成鼓励文案。 实现对齐 Luogu-Plus：改写 .lg-punch-result 与 .am-u-sm-6。 运势节点只在今日已打卡后出现，打完卡即被改写。

题号与搜索

选中任意文字，只要里面有题号（P / B / CF / SP / AT / UVA / U，以及 4 位以上纯数字）， 就弹出面板列出全部题号，点一下在新标签打开。规则与 Luogu-Plus 的 Problem Jumper 一致。

首页那个「问题跳转」盒子改成「问题搜索」：回车或点搜索时，4 位以上纯数字按 P 题号、 数字+字母按 CF 题号直达，认不出来才走全文搜索。「随机跳题」升级成可按难度与来源 （洛谷 / CF / SPOJ / AtCoder / UVa）抽题。

时钟

时钟字体

板块显隐

只藏不删：数据都在，重新打开开关就回来。改完首页实时生效，不用刷新。

已保存账号

每个账号使用独立的会话分区（cookie 互不干扰）。点「切换」会把所有已打开的洛谷标签页整体切到该账号；登录态未过期时自动进入，无需再输密码。

添加账号（验证成功才会保存）

验证流程：程序在后台打开登录页并填好账号密码；图形验证码先用 ddddocr 自动识别（最多 3 次），连续没过才把图放大 4 倍显示在这里让你填。验证通过 → 账号写入本机 %APPDATA%\LuoguLab\accounts.json；失败 → 不会留下任何记录。

注意：密码以明文保存在上面那个本机文件里（方便自动登录），请勿把该文件分享出去。

地址栏映射

例：deepseek → https://chat.deepseek.com。站外地址会在应用内新标签打开。

翻译服务

目标语言自动判断：中文 → 英文，其他 → 中文。%s 是待翻译文本（自定义端点走 GET，返回纯文本）。 必应为 Edge 同款免费接口，无需密钥；若服务端调整导致失败，会在气泡/悬浮条上明示。

用法：选中文字右键「翻译所选内容」；整页翻译在命令面板（Ctrl+Shift+P）搜「翻译整页」。

下载

关闭（默认）：统一存到「下载/Luogu++」，下载面板里可「另存为」； 开启：每次弹系统另存为对话框。下载记录会保留（重启后未下完的标为中断，可「重试」）。

清除浏览数据

含 localStorage / IndexedDB，覆盖默认、站外共享与全部账号分区。 ⚠️ 清除会退出洛谷登录态（需重新登录）。

快捷键 Ctrl+Shift+Delete 可直接打开这一页。
