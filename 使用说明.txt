LuoguLab v3.8.0 — 洛谷编程工作台
================================

【是什么】
双击 LuoguLab.exe 即可打开。这是一个把洛谷(luogu.com.cn)装进自带浏览器
外壳的桌面工作台,黑白线条风、极简界面,没有广告杂物。
无需安装,整个文件夹就是全部,可任意移动或删除。
你的设置与登录状态保存在 %APPDATA%\LuoguLab\,删掉这个文件夹即恢复全新。

【v3.8.0 新功能】(悬停不再闪一下 / 顶栏两行 / 窄条只留三角+钉子 / 坞可换边 /
              缩放不带走背景 / 验证码自动识别)

- 悬停展开不再"闪一下":以前鼠标贴上窄条,外壳先把自己的窄条隐掉,而浮层(另一个
  视图)还没画出来——中间那一两帧两边都没有侧栏,看着就是一闪。现在改成"浮层画好
  了再收窄条"(弹层回报之后再交接),交接的那一刻两边是同一份像素,接得严丝合缝;
  信号万一没回来还有 320ms 兜底,不会一直露着窄条。另外弹层文档做了首帧透明处理、
  启动后会预热,第一次悬停也不会白闪一帧。
- 垂直栏顶栏改成两行:第一行只有当前网页的图标 + 描述(居中显示),右端是窗口三键;
  第二行才是 前进/后退 + 网址 + 账号芯片。顶栏总高 80px,页面区跟着自动让位
  (左侧那条侧栏仍然从窗口最顶通到最底)。
- 折叠窄条左上角只剩那颗向下的三角:原来并排两颗(标签页操作 + 展开/收起),现在
  收起态只留三角;那颗表示状态的图标换成了一枚钉子——钉住(常驻展开)时是竖直实心
  的钉,悬停浮层里是斜 40° 的"没钉住",点一下就是钉住。
- 缩放页面不再放大/移动背景:页面里的壁纸层以前跟着页面一起缩放(放到 150% 时
  只看得到背景左上角一块)。现在按缩放系数反向补偿——背景在物理像素上永远等于
  窗口几何,放大缩小只影响网页内容,背景纹丝不动(与外壳、弹层那两层一致)。
- 设置 → 外观 → 侧坞新增「坞的位置」:跟随布局 / 左 / 下 / 上 / 右 五选一。
  以前坞固定在"水平布局左侧、垂直布局底部";现在四个边都能放,页面区按同一个
  值让位(坞不会盖住网页),换边后选中指示线跟着转方向;坞放右边时右边缘会让开
  右侧栏,不会钻到侧栏底下。
- 添加账号的图形验证码改成自动识别:用本机 ddddocr 自动过(常驻一个小进程,
  不弹控制台窗口),最多自动试 3 次;3 次都没过才把放大图亮在设置页请你手动输入。
  本机没装 ddddocr 时这条链路自动放弃、直接转人工,不影响使用;批量脚本
  add-accounts.bat 仍走它自带的外部识别流程(不跟它抢)。

【v3.7.1 新功能】(悬停展开重做:和"钉住展开"一模一样的一整条)
- 鼠标放到左侧窄条上,展开的不再是"半透明小卡片",而是和点箭头钉住后完全
  一样的一整条侧栏:从窗口最顶一直到最底、方角、贴边,把窄条整条盖住;
  "新建标签页 / 设置"也落在和钉住时完全相同的位置(原来面板只有内容那么高,
  下面空一大截,还带圆角和阴影,看着像个下拉菜单而不是侧栏)
- 展开时左边窄条整条隐去(原来它一直在面板底下继续画:左上角两颗小按钮透上来、
  面板下缘之后还有一条窄条,两块拼不上)
- 修掉一个更底层的问题:悬停面板背后的"壁纸"以前是按面板自己的尺寸铺的
  (被压成一小片),所以面板和旁边那条侧栏看着不是一块料;现在按整个窗口铺,
  悬停展开与钉住展开逐像素一致(探针在同一矩形上做像素对拍把关)
- 手感:鼠标贴上 80ms 展开(原来 50ms 太容易误触,光标扫过左缘就弹),
  展开动画 150ms(Edge 那一档),移开 200ms 收回
- 悬停卡片(完整标题 + 网址)跟着让位:展开时贴在面板外缘,不再被整条面板盖住
- 顺手修:悬停面板的点击区与面板严丝合缝(原来右侧多出 12px 透明区,
  盖在网页上吃点击)

【v3.7.0 新功能】(垂直侧边栏对齐 Edge + Edge 式标签分组)
- 垂直标签栏照 Edge 的样子重做:
  · 鼠标贴上窄条 = 整条侧栏"长出来"(图标变成带名字的整行,盖住窄条)
    —— 就是 Edge 悬停时的样子;移开自动收回,不挤压网页
  · 顶部一个箭头按钮:点一下常驻展开(真加宽、把网页挤到一边),再点收起
    (原来的「钉住」并进这颗箭头)
  · 窄条上的图标位置与展开后逐像素对齐 —— 鼠标贴哪一行、点下去还是哪行
  · 拖拽排序:拖动时显示插入位置线,拖到分组上整组高亮,拖进/拖出钉住区
    就是钉住/取消钉住(Edge 行为)
  · 悬停卡片:鼠标在标签上停一下,旁边浮出完整标题 + 网址
  · 侧栏宽度可拖:展开时拖侧栏边缘调宽窄(160~400px),下次打开还记得
  · 侧栏可以放右边:设置 → 外观 →「窗口与布局」→ 侧栏位置(左/右)
- 标签分组做成 Edge 那样:
  · 组头单独一行(折叠三角 + 色点 + 组名 + 个数),组内标签缩进,整组左边
    一条连续组色线;点组头折叠/展开
  · 双击组名就地改名(回车提交、Esc 取消)
  · 多选建组:Ctrl+点击加选、Shift+点击连选,然后右键 →
    「用选中的 N 个标签新建分组」(和 Edge 一样)
  · 拖标签进/出组:拖到组里就入组,拖出去就退出
- 搜索标签页(Ctrl+Shift+A)做成 Edge 那种大列表:图标 + 标题 + 网址,
  顶部显示「共 N 个标签」,↑↓ 选择、Enter 切换、Esc 关闭

【v3.6.0 新功能】(浏览器功能补齐 + 竖栏重做 + 整理标签页齐活)
- 垂直标签栏照你的要求重做:
  · 默认收成窄条;鼠标一贴上,完整标签面板"悬浮滑出"浮在网页上,
    移开自动收回 —— 这一下不挤压网页
  · 点「钉住」才是真正展开(把网页往右挤),再点取消就回到窄条
  · 切到水平标签条再切回垂直,原来的展开/收起状态按原样带回
  · 修掉四个老毛病:紧凑模式左上角空一条、悬停面板盖住窄条点不到底下
    的 +/设置、拖拽排序后钉住的标签和折叠组乱跑、窄条上不能关闭/右键
- 整理标签页(右键标签、标签页操作菜单、命令面板 Ctrl+Shift+P 都有):
  · 按站点排序 —— 每个分组块内部排,分屏成员保持相邻,钉住区不动
  · 关闭重复标签 —— 忽略 http/https、www.、末尾斜杠、#锚点;重复时
    保留哪一个可选(当前标签/最早/最近用,设置 → 页面)
  · 按域名自动建组 —— 同域名 2 个以上未分组标签自动成组,组名=域名
  · 干完弹出提示条带「撤销」(8 分钟内有效,关掉的标签连钉住/分组/
    原来位置一起还原)
- 工作区功能整块删除(配置里原本就是空的,零损失;旧配置下次启动自动清掉)
- 网页右键菜单(和别的浏览器一样):复制/剪切/粘贴/全选;选中文字可
  「翻译所选内容」;链接可新标签打开/后台打开/复制;图片可另存为/
  复制地址;视频可画中画;页面区可后退/前进/刷新/复制网址/
  完整网页截图/检查元素
- 下载增强:暂停/继续/取消/重试/在文件夹中显示/另存为;下载记录重启
  还在(没下完的标「已中断」,点重试继续)
- 历史增强:按日期分组(今天/昨天/日期)、可搜索、可单条删除
- 清除浏览数据:设置 → 其他 →「清除浏览数据」(缓存 / Cookie 与站点
  数据 / 历史 / 下载记录,勾哪清哪;Ctrl+Shift+Delete 直达)
- 地址栏联想:输入时下拉出历史与映射词,↑↓ 选择、Enter 打开、Esc 关闭,
  最后一行固定是「搜索 xxx」
- 搜索引擎可切换:设置 → 页面 →「搜索」可选洛谷/必应/百度/谷歌/
  DuckDuckGo/自定义(填含 %s 的地址);地址栏、首页搜索框、联想共用
- 停止加载:网页加载中,刷新键变成 ×,点一下立刻停
- 整页截图:命令面板搜「截图:整页」或右键「完整网页截图」,长网页整张
  存下来(存到 shots 文件夹并提示)
- 阅读模式:命令面板搜「阅读模式」(可绑快捷键)——只留正文、纯色纸面、
  字号可调,Esc 退出还原
- 翻译:右键「翻译所选内容」划词译;命令面板「翻译整页」整页译,顶部
  悬浮条可切「原文/译文」、退出还原;默认必应翻译,设置里能换自定义
  接口;中文页自动译英、其它语言译中
- 窗口大小和位置会记住:下次打开回到上次的尺寸和位置(上次是最大化,
  这次还是最大化)
- 关软件时不再丢最后一次改动(标签存档、窗口状态退出前补写)

【v3.5.0 新功能】

  列表,移开自动收回;头部折叠按钮可固定展开/收起,重启记住状态

  分割条调比例(双击复位 50%);点哪一栏地址栏就管哪一栏;再右键「退出
  分屏」还原。命令面板也有「分屏:与相邻标签并排显示」
- 自定义快捷键:设置 → 其他 → 关于与数据,点「修改」按下新组合即可
  (Esc 取消),冲突会提示,「重置」回默认
- 设置页的文字可以框选复制了
- 壁纸去重更彻底(列表即去重),新增壁纸视差(鼠标移动壁纸轻微跟随,
  设置里可关);双击标签栏空白处换一张壁纸
- 玻璃全面统一:洛谷页面、外壳、弹层、DeepSeek 用同一套玻璃颜色和圆角;
  DeepSeek 不再有铺满整页的白底,侧栏也是玻璃了
- 切洛谷账号不再影响 DeepSeek 等其他网站的登录(站外网站改用独立会话;
  升级后首次其他网站需重新登录一次,以后永不波及)
- 洛谷页面变玻璃的速度明显变快(注入去重 + 壁纸零拷贝直出)

【v3.5.4 新功能】
- 多窗格拼合(分屏升级):右键标签「与当前标签分屏显示」后,继续右键
  第三个标签「加入当前分屏」,最多 4 个网页同屏——2 格左右并排、
  3 格左边通高+右边上下、4 格 2×2 网格;纵/横分割条都能拖(双击复位),
  关掉一格自动缩回 3 格,点哪一格地址栏就管哪一格

  块彩色组牌;左键点组牌折叠/展开(折叠时只剩组牌和个数),右键组牌
  开组面板——命名、10 种颜色、组中新建标签页、取消分组、关闭分组;
  拖动标签落进组中间=入组,拖出组=移出;重启后分组原样恢复
- 垂直模式下洛谷导航坞挪到窗口正下方(Mac 式圆角玻璃浮框,与弹层
  菜单同一块玻璃),页面从此铺满全高,坞单独浮着不占地方

- 水平标签多时自动收窄,再窄收成纯图标,右上角始终留一块空白;
  放不下时横向滚动(鼠标滚轮直接滚)
- 题库/训练/比赛/记录列表页上多余的「难度/排序」悬浮卡片已撤掉,
  只保留筛选行的输入即筛和条数提示
- 版本热更新:开发改动直接同步进本应用,不用等重新打包

【v3.5.5 新功能】
- 拼合布局大升级:右键分屏组里的标签 →「拼合布局」,15 种摆法任选
  (当前布局打勾):2 格=左右/上下;3 格=主窗格居左/右/上/下、等分三列、
  等分三行;4 格=2×2 网格、主窗格四向、等分四列、等分四行。主窗格
  布局里发起拼合的那个标签永远是大窗格
- 每道缝都能单独拖:网格左右两列的横缝互不影响(两列可以不一样高),
