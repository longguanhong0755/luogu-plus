# 洛谷桌面版（Luogu Desktop）

为 Windows 打造的洛谷客户端。**不是网页套壳**：没有地址栏、没有标签条、没有悬浮坞。
左边一条 72px 导航栏，右边是工作区；做题时是纯题面，按需开 IDE；关窗收进托盘。

## 目录结构

```
desktop/   当前应用（Electron 39）
  src/main/      主进程，按领域拆分：
                 index / config / theme / wallpaper / window /
                 views / luogu / tray / notify / ipc
  src/preload/   shell / settings / page 三个隔离桥
  src/renderer/  shell（标题栏/导航/主页/工具条/覆盖层）
                 settings（独立设置窗）
                 skin（洛谷页面统一皮肤）
legacy/    3.17.0 旧版 LuoguLab 完整归档（git 历史保留，可作参考/回退）
```

## 开发

```bash
cd desktop
npm install
npm start          # 启动
npm run check      # 静态检查：语法、必需文件、HTML 引用、IPC 双向对齐
npm run smoke      # 不可见启动 + 截图到 ../.lg-dev/（隔离 userData）
npm run gen:icons  # 重新生成应用/托盘/角标图标
```

## 设计

- **主页**：日期 + 每日寄语 + 签到 + 打卡网格（近 20 周，由提交记录聚合）+ 比赛倒计时 + 最近提交。
- **浏览**：题库 / 训练 / 比赛 / 讨论 / 记录，用洛谷真实页面 + 统一皮肤；站点顶栏和站内左栏隐藏，由应用导航接管。
- **做题**：纯题面沉浸；IDE 模式左右 50/50；提交走页面会话，评测完成弹系统通知并挂任务栏角标。
- **设置**：独立小窗，改动即时生效。四根风格轴——明暗（浅/深/跟随系统）、材质（纯色 ↔ 玻璃）、壁纸（桌面/内置/每日一图/自定义）、强调色（洛谷蓝/系统色/自定义）。
- **无标签**：板块单例常驻、切换零加载；`Ctrl+Tab` 切换已打开页面；`Ctrl+K` 输题号直达。
- **站外链接**一律交给系统默认浏览器；应用内只渲染洛谷。
- 无动画、不记忆会话（每次启动回到主页）。
- 托盘常驻：左键显隐窗口，右键签到/设置/退出；关窗行为可在设置里改为直接退出。
- 单实例：重复启动会聚焦已有窗口。

## 边界

- 只读写应用自己的 `userData`；测试用 `LG_USERDATA` 指向隔离目录。
- 测试窗口全程不可见（`opacity=0` + `showInactive`），不抢焦点。
- 设置里可关开机自启（默认关）；未登录时主页只显示登录入口和公开比赛信息。

## 说明

洛谷页面的数据在 `#lentille-context` 的 JSON 里；皮肤通过改写 `--theme-*` 变量实现，
并借助系统主题源让站点走官方深色主题，避免逐类覆盖导致语义色丢失。
