LuoguLab v3.16.7 — 洛谷编程工作台
================================

【是什么】
双击 LuoguLab.exe 即可打开。这是一个把洛谷(luogu.com.cn)装进自带浏览器
外壳的桌面工作台,黑白线条风、极简界面,没有广告杂物。
无需安装,整个文件夹就是全部,可任意移动或删除。
你的设置与登录状态保存在 %APPDATA%\LuoguLab\,删掉这个文件夹即恢复全新。

【v3.16.7 更新】(真实点击走查 / 细节修复)

这一轮把"能用"往"顺手"推了一步，重点修真实鼠标点出来的毛病。

- 首页时钟和日期、搜索框和下方提示的间距恢复设计值（此前的负值写法浏览器
  不认，整条间距被丢掉）。
- 设置页的滑杆整条 28px 高都能点、能拖；以前只有一条 3px 的细线能命中，
  点偏一点完全没反应。
- 地址栏联想下拉加宽到 480px，标题和网址不再挤成一团；菜单和联想面板不再
  多出一圈黑色焦点框。
- 竖直窄条里点标签图标不会再误关标签（关闭叉缩小并让出图标中心点）。
- 设置页说明文字、首页卡片标题与时间、账号邮箱、菜单快捷键等次要文字统一
  加深，在亮壁纸下也能看清。
- 地址栏、账号芯片对齐到 32px 控件刻度；菜单行高统一到 28px。

【v3.16.6 更新】(核心手感 + 反馈)

这一轮不加新功能，只把「按了像没按」「坏了没人知道」的地方修好。

- 命令面板、F1 快捷键表、标签搜索、页内查找条改到弹层里显示：以前它们
  画在窗口边框上，网页标签一盖就整个看不见；现在浮在网页上面，方向键
  上下选、回车执行、Esc 关闭都可用。
- 键盘焦点跟着界面走：Ctrl+L 回到地址栏，面板关闭后焦点回到网页，切标签
  后光标就在那个标签里——以前焦点留在旧页面，敲键盘打到了别处。
- 账号菜单每 0.7 秒刷新一次，验证码输入不再被冲掉：输入到一半也不会丢
  焦点、丢光标位置。
- 界面缩放 80%~140% 时，网页不再压住侧栏和顶栏，弹层仍然贴着按钮。
- 危险操作先问一句：恢复默认设置、删除账号、清空历史、清空下载记录。
- 失败会说话：网页加载失败、下载中断、配置写不进磁盘、整页截图失败，
  都会弹提示，并带上「重试」「查看下载」「诊断」入口。
- 登录过期不再装作还登录着：用户名处显示「已过期 · 重新登录」。
- 顺带修掉两处小毛病：历史页标题栏的排版；设置页打开时 22 张卡片闪一下
  再收起。

【v3.16.5 更新】(设计系统加固 / 界面像素级统一 / 升级后样式立即刷新)

这一轮不加新功能，只按像素级规范把界面的尺寸与间距统一收一遍。

- 按钮、输入框、开关、侧栏项统一到三档控件高度(28 / 32 / 40)，
  同一屏幕里不再出现 24 / 28 / 30 / 40 混排。

  不再出现浏览器默认的 13.3333px 这种发糊字号。

  卡片里的输入框、弹层里的按钮不会再出现两层同半径的胖角。

- 本地页的样式与脚本改用应用内协议加载，升级后不会再出现
  "外壳已经是新版、样式还是旧版"的缓存问题。

【v3.15.0 更新】(数据不丢 / 失败可见 / 守卫补齐)

这一轮不加新功能，只把"悄悄坏掉"的地方修成"坏了会说话"。

- 配置、账号库、浏览历史、下载记录、标签存档改为**原子写入**：先写临时文件
  再整体替换。以前是直接覆盖目标文件，进程在写一半被结束（断电、任务管理器
  结束进程）会留下半个 JSON，下次启动读不出来就回到默认值——表现为"我的设置
  或账号自己没了"。
- 存档损坏会**先备份**：任何一份数据读不出来时，先把坏文件另存为
  `xxx.json.corrupt-<时间>`，再回退默认值，并在启动后提示一次。以前是无声无息
  回退，紧接着一次保存就把原文件覆盖掉，原数据再也找不回来。
- 写不进去会**告诉你**：磁盘满、没有写入权限这类失败以前被完全吞掉（改了设置
  毫无反应，以为是软件卡了），现在会写日志并在界面上提示一次，附带是哪个文件
  没存下来。
- 修掉两处"看起来在测、其实永远测空"的断言：配置探针读的 `--lg-alpha-card`
  这个变量早就不存在（面不透明度 v6 已合并成 `faceAlpha`），报告里那个字段一直
  是空串；注入页 preload 里挂着一个写死的 `version:"6"`（应用已经 3.15.0）且
  全库没有任何地方读它。前者改读真实下发的材质变量，后者删除。
- 默认值对齐真实语义：配置里 `pageTheme` 的默认值原写 `native`（注入层早已不再
  接受的值，实际跑的是 `auto`），改为 `auto`。
- 材质守卫补上**投影口径**：外投影（裸 rgba 黑）不受材质变量控制，是"内外同料"
  的最后一块缺口。存量 6 处钉成基线，新增一处即报错；违规报出的行号也修准了
  （以前注释被整块剥掉会让行号前移，按它去找会找错行）。
- 测试脚本：探针启动前强制清掉宿主可能注入的 `ELECTRON_RUN_AS_NODE=1` ——
  该变量会让 Electron 退化成 Node，所有 `--lg-*` 被当成非法选项，探针看起来
  "跑了"其实一次都没启动。
- 新探针 `--lg-v315test`：23 项断言，逐条真跑（坏文件备份、原子写、失败文案、
  六个持久化点、投影基线、死字段），不再只查字符串。

【v3.14.0 更新】(性能极致优化 / UI 风格统一)

性能(全部有前后基线对拍,新探针 --lg-perftest 量化验收):
- 后台标签节流(设置可关):非活动标签恢复 Chromium 默认定时器节流——旧版所有
  页面视图都关了节流,后台网页的定时器永远全速跑,标签一多 CPU 白烧。活动标签、
  分屏、正在放声音的标签不节流;"窗口隐藏后首帧发黑"的旧问题由强制重绘兜底,
  与节流无关。
- 标签惰性恢复:开了"恢复上次的标签"时,启动只真开活动标签/分屏/钉住的,其余
  恢复成睡眠态(标签位/标题/分组都在,点一下才加载)——启动不再同时发起 N 路
  网络加载,冷启动内存大降。休眠标签的标题现在直接从存档带回,不再显示一排
  "新标签页"。
- 内存紧张自动休眠(设置可关):系统可用内存不足(约 1.5GB 或 15%)时,把最久
  未用的后台标签提前休眠;原有的 30 分钟空闲休眠不变。
- 视频壁纸改流式:主进程不再把整个视频文件常驻内存,页面也不再每个标签拷一份
  完整字节——改走 lg-media:// 边下边播(按 Range 精确读盘);万一媒体加载器
  不认,4 秒内自动回退旧的字节通道,视频壁纸不会白屏。
- 用户态探测事件化:去掉"每 2 秒往当前页面注入一次脚本"的盲扫,改为导航完成/
  切标签/打开账号菜单时抓一次,30 秒兜底轮询。
- 标签条推送合并:页面加载期 loading/标题/图标一拍一个的全量推送(旧版一次
  加载能触发几十次标签条整体重建)合并到 80ms 一拍;外壳收到相同快照直接跳过。
- 其它:调试日志改批量落盘(以前广告拦截每个请求都同步写一次盘)、壁纸视差
  缓动 60fps→30fps、拖窗口不再逐帧全量重排(32ms 合并)、配置落盘改异步。
- 实测(同机对拍):6 个测试标签内存 680→636MB、休眠回收 69→97MB、唤醒 26ms、
  节流落位正确(活动关/后台开)。

UI 统一(行为不变,收的是"料"和"笔"):
- 修一个真 bug:首页"去搜索/随机跳题"两个按钮的边框声明里多了一个括号,
  那条边框从来没画出来过。
- 图标唯一来源:外壳/首页/设置页此前各养一份"同一份线稿"(实际是三套不同
  路径——坞里画一套、设置页预览另一套),现在收口到 src/icons.js 一份,设置页
  坞编辑器的图标预览与实际渲染完全一致。散落的文本 ×/↑/↓、💤 emoji、CSS
  三角箭头全部换成统一线稿 SVG。
- 字体/字号/圆角/滚动条/选区单一来源:字体栈此前 4 处定义 3 种等宽栈,统一进
  material.css;同角色字号(11/11.5px、12.5px)归到 --fs-sub/--fs-base 令牌;
  滚动条两份重复定义合一;补全亮色/暗色统一的文字选区色。
- 首页私有 --h-* 色板并入全应用共享词汇(顺带修了深色解析下首页墨色从没跟上的
  潜伏问题);表格条纹/悬停斑马纹、散落的灰色值改由墨色令牌按透明度派生,明暗
  自动跟随。
- 拖拽小提示(外壳与弹层各写一份)收口为一份;三处裸内联的"桥接失败"错误页
  换成统一错误卡;删掉从未被 JS 引用的死样式(.gchip/.vgchip/.tm-check)。
- 材质守卫(material-lint)扫描范围扩到 main.js 的内联样式,口径收齐。

【快捷键】
Ctrl+T 新标签      Ctrl+W 关闭标签     Ctrl+Tab 切换标签
Ctrl+L 聚焦地址栏   Ctrl+R / F5 刷新    Alt+左右 后退/前进
Ctrl+I 打开/回到IDE Ctrl+Alt+I 分屏编辑器  Ctrl+H 历史记录
Ctrl+Shift+P 命令面板
Ctrl+Shift+O 整理标签页   Ctrl+Shift+Delete 清除浏览数据
Ctrl+= / Ctrl+- / Ctrl+0  放大 / 缩小 / 重置页面缩放(每个标签各自记忆)
Ctrl+滚轮  直接缩放鼠标所在页面
F1 快捷键总览      F2 设置            Ctrl+Q 退出
(设置 → 其他 → 关于与数据 里可以把这些键改成自己喜欢的)

【登录与账号】
设置 → 账号:填一次洛谷账号密码,验证通过后才会保存。
之后在顶栏头像那里一键切换账号,每个账号的 cookie 完全隔离,互不影响。
账号密码保存在本机 %APPDATA%\LuoguLab\accounts.json(明文,仅本机可用)。

- 切换前会先探测目标账号的会话还在不在:在就直接换分区,不用重新登录、
  不用过验证码;真失效了才走登录流程。
- 本机已入库 10 个账号,每个都有独立分区与独立 cookie。
- 再要批量加账号:运行 `add-accounts.bat`(在应用目录里),把账号按
  每行 `邮箱----密码----用户名` 粘进弹出的文本文件,保存后回车即可。
  图形验证码由本机 ddddocr 自动识别,不用人工读图。
- 应用内的「添加账号」同样自动识别:先自动试 3 次(ddddocr),3 次都没过才把
  放大图亮出来请你手输;本机没装 ddddocr 就直接转人工。
- 应用内的「添加账号」同样自动识别:先自动试 3 次(ddddocr),3 次都没过才把
  放大图亮出来请你手输;本机没装 ddddocr 就直接转人工。
