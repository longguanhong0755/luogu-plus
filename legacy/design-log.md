## 关于参考项目 O2-luogu 的核查结论（诚实记录）

用户要求参考 <https://github.com/TLEWA/O2-luogu>。该仓库是 **Stylus 用户样式「氧洛谷」**
（发布在 userstyles.world/style/18339，GPL-3.0，主文件 `O2luogu-userstyle.styl`），
`configs/Default.json` 里有 **401 个配置键，全部是 CSS 变量**
（`Card-L1-radius`、`Code-block-keyword-color`、`Topic-difficulty-Label-1..8`、
`Font-Stack`、`SideBar-position` 等）。

- **它强而我们曾经缺**：细粒度视觉可调。R11~R12 已补上配色预设 + 六个细调项。
- **它没有而我们强**：应用外壳、多标签、账号体系、列表工具条、分屏编辑器、书签/历史/下载。
- **没有照搬的部分及原因**：本产品视觉规范是黑白单色线条风，而 O2 的 401 个变量里
  很大一部分是彩色主题色（代码高亮、难度色阶）。实测洛谷新前端的代码块
  （`pre.lfe-code`）**不含任何语法 token 元素**（`--lg-dump-tokens` 探针为证），
  没有可着色的目标，所以"代码高亮配色"没有落地基础；难度色阶则提供灰阶化开关
  （`diffMono`）而不是照抄 8 色。
