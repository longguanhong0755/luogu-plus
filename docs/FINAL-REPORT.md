## 一、一页速览

LuoguLab 把 luogu.com.cn 装进一个自带的浏览器外壳里，并且是**可以按你的习惯逐项改造的外壳**。它做了四件事：

1. **换掉洛谷自己的顶栏和侧栏**，改成应用级的标签栏 + 工具行 + 站点快捷 + 账号芯片；洛谷页面本身被当成内容区注入。
2. **给页面套一层可开关的美化与功能层**：三态配色 × 5 套配色预设、去广告、页面精简、列表页筛选、题目页分屏编辑器、代码块一键复制、阅读模式、划词/整页翻译。
3. **补齐浏览器该有的能力**：页面缩放、标签拖拽排序/分组/四分屏、标签与网页两级右键菜单、停止加载、搜索引擎可切换、地址栏联想、历史、下载接管（暂停/继续/重试/另存为）、清除浏览数据、整页截图、画中画、命令面板。
4. **管住多个洛谷账号**：每个账号一个独立的 cookie 分区，顶栏一键全局切换，不用再登出登入。

三个阶段的状态：

| 阶段 | 状态 |
|------|------|
| 设计迭代（R1–R24，**24 轮**，每轮都有截图或 JSON 断言证据） | 完成 |
| 收尾规范实现（垂直标签栏 / 三态配色 / 账号体系 / 全部功能开关 / 设置页分组） | 完成 |
| 打包部署（便携版 + 桌面成品） | 完成 |

### 3.2 页面配色：主题色 × 中性基色 × 三态

**这一节在 3.1.0 里重做过。** 原先的深色模式是"整页反色滤镜"，观感差且无法上色；
现在改成 **主题色种子系统**：用户挑一个颜色（比如紫色），洛谷页面与应用外壳的所有
色块都跟着它走——卡片底、页面底、正文、边框按**不同比例**朝它混色。

混色比例是固定的一组常数，所以**任何色相都能自动适配**，不需要为每个颜色单独调色：

| 层 | 亮色混入 | 暗色混入 | 为什么是这个比例 |
|----|---------|---------|-----------------|
| 卡片底 `tint` | 46% | 44% | 最重——"选了紫色所有块变紫"看的就是它 |
| 页面底 `bgBase` | 26% | 32% | 比卡片淡，保住层次 |
| 正文 `ink` | 30% | 26% | 最轻，保证对比度与可读性 |
| 边框 `border` | 55% | 55% | 只换 RGB 保留 alpha，线条轮廓在任何色相上都成立 |

实测（`colortest.json`）：选紫 `#8b5cf6` → `tint 216,200,247 / ink #3a2c47 / bgBase #e3d7eb`；
选绿 `#22c55e` → `tint 182,234,198 / ink #244227`。卡片实测背景 `rgba(216,200,247,0.35)`。

**三态开关决定"要不要接管页面"：**

**三态开关决定"要不要接管页面"：**

| 模式 | 行为 |
|------|------|
| **原色**（默认） | 完全不干预洛谷配色：不套主题、不去色。只保留"隐藏洛谷原生顶栏/侧栏"这一层结构性注入 |
| **亮色** | 给页面套上应用的单色线条皮肤：卡片改素面 + 发丝边框、去阴影、等宽代码块、表格细线 |
| **暗色** | **整页重绘**为深色 |

**5 套预设决定"接管之后长什么样"**（全部是中性灰阶，差别在色温与对比度）：

| 预设 | 亮色 | 暗色 | 调性 |
|------|------|------|------|
| **墨白**（默认） | `#f7f7f8` / `#18181b` | `#101013` / `#e7e7ea` | 纯中性灰阶 |
| **宣纸** | `#f6f2e9` / `#241f18` | `#141210` / `#e9e2d5` | 微暖米灰，久看不刺眼 |
| **青灰** | `#f1f4f7` / `#141b21` | `#0c1013` / `#e1e8ee` | 微冷青灰，接近工程灰 |
| **柔雾** | `#fafafb` / `#3f3f46` | `#17171a` / `#d4d4d8` | 低对比柔灰，弱化边框 |
| **高对比** | `#ffffff` / `#000000` | `#000000` / `#ffffff` | 纯黑白，边框加重 |

**细粒度调项**（设置 → 视觉细节，全部即时生效）：

| 项 | 范围 | 作用 |
|----|------|------|
| 强调色 | 自动 / 墨 / 炭 / 灰 / 银 / 自定义 | 应用接管的按钮、悬停态、链接 |
| 圆角 | 0–20px | 卡片、输入框、按钮 |
| 卡片不透明度 | 30%–100% | 页面卡片底 |
| 毛玻璃模糊 | 0–40px | 卡片背景模糊 |
| 外壳不透明度 | 30%–100% | 顶栏与标签栏底 |
| 边框强度 | 40%–300% | 发丝线的深浅 |
| 页面动效 | 开 / 关 | 关掉后页面内所有过渡与动画立即停 |

配色架构上做了一件重要的事：**主进程是色表唯一权威**，算好 `presetLight`/`presetDark` 随配置下发，页面侧、外壳层、设置页三处只贴不算；外壳与设置页的中间色由四个基色用 CSS `color-mix()` 派生。这样加一套预设只需要在一个地方写四个色值。

**液态玻璃皮肤也继承主题色。** 这是一个真被踩到的坑：玻璃卡片的底色原先写死
`rgba(255,255,255, α)`，于是开了玻璃皮肤后"选紫色所有块变紫"完全失效（卡片永远是白的）。
现在改成 `rgba(var(--lg-tint), α)`，外壳玻璃同理改用 `color-mix()` 取当前 surface。
修复前后实测：`rgba(255,255,255,0.35)` → `rgba(216,200,247,0.35)`。

配色架构上做了一件重要的事：**主进程是色表唯一权威**（`hexToRgb` / `mixRgb` / `SEED_MIX`），
算好派生色随配置下发，页面侧、外壳层、设置页三处只贴不算。这样换颜色只需要改一个种子值。

### 3.14 页面透明失效修复（v3.4.2）

用户反馈"无法正常变透明"：页面完全是洛谷原生样子——原生顶栏还在、页面不透明白底、壁纸只以一条 157px 的横带出现在页面顶部。探针 dump 定位到根因不在配色，而在**样式表根本没进页面**：

| 现象（探针实测） | 解释 |
|---|---|
| 注入的 JS 状态全在（`data-lg-wall="1"`、CSS 变量、`#lg-glass-bg` 元素都建了） | JS 每次加载都会重灌，没问题 |
| 但 `body` 仍是站点自己的 `rgb(255,255,255)`、原生 `.top-bar` 仍是 `display:flex`、壁纸层 `position:static` 且只有 1367×157 | 注入的 **CSS 完全不在文档里** |
| `--lg-dbg1` 对照实验：旧逻辑在整页 reload 后 3/3 丢失样式；新逻辑 3/3 立即恢复（0ms） | 旧逻辑是"插过就不再插"的布尔标记 |

根因：CSS 是"每个文档一份"的。站点在版本更新后会自刷新一次整页（`[lentille/config] Updated local store` → reload），旧文档连同插进去的样式表一起销毁；而 `wc.__lgCssDone` 这个布尔标记还挂着 `true`，新文档的 `dom-ready` 便永远跳过插入。于是页面回到原生外观，且只有重启应用才能恢复。注意站点自刷新在 Electron 里报 `did-start-navigation(isInPlace=true)`，靠导航事件复位标记也不可靠。

修复：不再用布尔标记，改为每次注入**先 `removeInsertedCSS(上一张)` 再 `insertCSS`**（同一文档重复调用不会堆叠，换文档后旧 key 的 remove 是空操作）。修复后 `body` 计算色 `rgba(0,0,0,0)`、壁纸层 `position:fixed` 铺满视口+内边距（实测 1430×920）、原生顶栏 `display:none`。

### 3.17 九项功能迭代（v3.5.0）

围绕"玻璃统一、提速、会话隔离、Edge 式垂直栏、分屏、可定制"九项需求做了一轮功能迭代。新增 `--lg-v35test` 探针逐项断言（玻璃一致性/会话三分区/切账号隔离/分屏几何/快捷键合成/垂直栏持久化/壁纸去重/快道标记/标签操作菜单/右键分屏项），连同 configtest（配置往返/12 项右键菜单含分屏/28 条面板命令/24 行快捷键）、pagetest、featest、r8test（DeepSeek 实测 `glassSite:1 / dsTheme:light / body 透明 / 零 backdrop-filter`）全部跑绿。

| # | 需求 | 根因 → 实现 |
|---|------|------------|
| 1 | **洛谷页玻璃出现得太慢** | 三处叠加：dom-ready 与 did-finish-load 各跑一遍完整 inject（CSS 拔插×2）；inject.js 每 2.5s 无条件全量 apply（重挂/重拆功能块）；主因是壁纸异步（每标签全量读盘 + IPC 传 ~590KB + 页面分块 base64，到之前玻璃背后是实色）。→ 注入按文档去重（did-finish-load 只补轻量 apply）；轮询改为"扫查照常、URL 变才 apply"；壁纸走 `lg-media://` 直出（协议本就注册 `bypassCSP+stream`，探针 Image 失败才回退 IPC data URL），视频壁纸同样直放优先 blob 兜底，主进程字节按 path+mtime 缓存（不再每标签读盘） |
| 2 | **页面玻璃与外壳玻璃不同色** | 明暗判定三口径（页面嗅 DOM、外壳读 lastNative、本地页看系统主题）+ 玻璃曲线两套（外壳 color-mix、页面 rgba）。→ 明暗由主进程 `resolvedTheme()` 一处裁决随配置下发；新增 `glassVars(mode)` 作为全应用唯一玻璃算法（bg/bg2/card/line/hi/sheen/blur/drop + 玻璃站专用的 soft/solid 可读档），外壳/页面/弹层/本地页全部消费同一张映射 |
| 3 | **DeepSeek 白底层 + 侧栏没玻璃** | glassSite 被强制发浅色变量（恒白兜底渐变 + 白纱），令牌是 0.82~0.95 近不透明黑白。→ 玻璃站明暗改吃 `data-lg-dstheme` 嗅探（巡检复嗅防 SPA 首屏嗅错），选同源 glassVars；删白色画布纱；`--dsw-*` 令牌全部改消费 `--lg-glass-*`（侧栏 glassSoft 玻璃化，输入框等正文面 glassSolid 保可读，仍零 backdrop-filter） |
| 4 | **切洛谷账号把 DeepSeek 登出** | 所有 http(s) 标签都跑 `persist:acct-<id>`，切账号把站外标签一起重建进新分区。→ 会话三分：本地页=default、洛谷系=账号分区、其他 http(s)=新增 `persist:shared` 共享分区；切账号/同账号重载只动 `isAllowed` 的洛谷标签（站外标签 id 不变、不 reload）；shared 分区补下载接线与权限拦截。一次性代价：站外站首次需重登一次 |
| 5 | **玻璃块代码不统一** | 与 #2 同根：玻璃派生层外壳/页面/弹层各写一份。→ 全部收敛到主进程 `glassVars()` 一处（CSS 只消费变量），圆角/浓度/模糊同一 cfg 出处 |
| 6 | **Edge 式垂直标签栏** | 折叠状态只在内存（重启丢）、无悬停展开、无标签操作菜单。→ `cfg.vtabCollapsed` 持久化（默认收缩成 46px 窄条）；窄条悬停 120ms 经**弹出层**浮出完整标签列表（站点视图永远压外壳，纯 CSS 加宽会被网页盖住，Edge 的悬停展开正是浮层），进出浮层靠 `popup:hover` 回报协调收回；新增标签操作菜单（垂直/水平切换带对勾、整理标签页=按站点分组排序/关闭重复标签、折叠展开、标签设置），垂直栏头部与水平条左端各一颗入口 |
| 7 | **分屏（同窗口并排两网页）** | layout 所有标签共用同一矩形、同一时刻只显示一个 view。→ 主进程 `splits` 双向记录（含固定 left 与 ratio），活动标签有伙伴时两 view 左右同显；`webContents focus` 事件做焦点路由（地址栏/快捷键跟焦点走，几何不动）；两栏间留 6px 缝露出外壳，`#splitbar` 直接收指针事件拖拽改比例（双击复位 50%）；IDE 抽屉优先（开着分屏挂起）；右键菜单"与当前标签分屏显示/退出分屏" + 命令面板两条命令；分屏对按下标持久化，重启回链 |
| 8 | **设置页不能框选文字 + 快捷键不可改** | `user-select:none` 写死在 body；快捷键全靠菜单加速器写死，且 SHORTCUT_ROWS 与 chrome.js 各抄一份。→ 设置页默认可选（仅控件表面排除）；新增 `SHORTCUT_ACTIONS` 动作表一处维护（菜单加速器/设置页/F1 总览/命令面板 hint/全局热键全部派生），`cfg.shortcuts[id]` 覆盖（""=解绑），设置页点"修改"捕获下一次按键（Esc 取消、冲突拒绝、可重置），非法键位自动回退默认表 |
| 9 | **壁纸重复 + 想与背景互动** | 去重只在启动/手动/导入时跑：list 不去重（网格照单全收）、旧 pick-wallpaper 通道跳过 md5、WE 壁纸不计判重。→ `lg-wall:list` 列目录即去重（md5 按 path+mtime+size 缓存零成本）、旧通道同内容直指不复制、WE 内容计入判重集。互动：壁纸视差（页面层 mousemove 本地动 + 节流 66ms 经主进程转发外壳，两层同一公式同步动不错位，可关）；双击标签栏空白/垂直栏空白换一张 |

**部署**：同步进 app-extracted 后 asar 重打包（旧包备份为 app.asar.bak-3.4.5），部署版 exe 冒烟（configtest + v35test）全绿。

### 3.18 十项打磨 + 热应用迭代（v3.5.1）

一轮"挑刺"修复：标签图标、拖拽区误吞点击、里外配色分裂、壁纸错位、侧坞编辑器全摊开的连环 bug，外加把迭代方式本身改成热应用（`scripts/dev-hot.sh` 一条命令进热应用模式，工作区源码改完即见）。

| # | 需求/问题 | 根因 → 修法 |
|---|----------|------------|
| 1 | **地址栏输网址跳转后标签图标不变** | 两处叠加：`page-favicon-updated` 给的是**数组**，整个塞进 `t.favicon` 后被 `img.src` 拼成 "url1,url2" 永远加载失败退回默认页标；且导航时旧站图标不复位，新站事件没来时一直挂旧图标。→ 导航开始即清 favicon；事件取数组首项；did-finish-load 仍无图标则按惯例试 `<origin>/favicon.ico`（404 由外壳 img onerror 兜底回页标） |
| 2 | **左上角向下箭头（标签页操作）点不动** | `#tabstrip` 是窗口拖拽区（`-webkit-app-region: drag`），新增的 `#tabs-more` 没补 `no-drag`——点击被系统当拖动吞掉。→ 补上即恢复 |

| 5 | **首页考试倒计时在外面，要到中间来** | 倒计时挤在底部双卡区（首屏看不到）。→ 卡片整体挪到搜索框正下方居中，条目改横向药丸排布，最近一场一眼看到；原双卡区由近期比赛独占整行 |

## 五、账号体系

### 目标

> 「提供账密之后确认账号存在之后，后续只要在特定的页面然后点击切换到 xx 账号就自动切换过去」

### 怎么做

- **一个账号一个会话分区**：`session.fromPartition("persist:acct-<id>")`。每个分区是独立的 cookie / localStorage / 缓存，账号之间永不串号。未保存账号时用默认会话。
- **添加流程必须验证成功才落库**：
  1. 设置页 → 账号 → 填邮箱 + 密码 → 「验证并添加」
  2. 主进程在后台（不弹窗）打开洛谷登录页：清 cookie → 首页 → 页内跳 `/auth/login` → 填账号 → 点「下一步」→ 填密码
  3. 遇到图形验证码：验证码图用 canvas **4 倍无插值放大**后回传到设置页，你读完填进输入框
  4. 提交 → 跳转成功才算通过 → 写入 `accounts.json` 并设为当前账号
  5. 验证码连错会刷新重来（最多 4 轮）；任意阶段失败 → 清掉该分区 cookie，**不留任何记录**
- **一键全局切换**：顶栏账号芯片下拉，或设置页账号列表。切换 = 换会话分区 + 把所有已打开的洛谷标签按原 URL 重新加载。
- **凭据存储**：`%APPDATA%\LuoguLab\accounts.json`，密码是**明文**（Electron 本地应用没有系统级密钥链可用；文件权限限于当前 Windows 用户）。不联网上传、不写日志。
- **昵称回填**：登录成功后从页面 DOM 读到真实用户名，回写进账号记录。

### 批量添加 + 验证码自动识别（v3.2.0）

一次给 9 个账号，靠人手一张张读验证码不现实，所以接了一条全自动链路：

| 环节 | 做法 |
|------|------|
| 清单 | `--lg-addacct-batch` + 环境变量 `LG_ACCT_FILE`，逐行 `email----password----username` |
| 出图 | 流程每 1.2s 把当前验证码落盘到 `<base>.cap.png`，状态落盘到 `<base>.json` |
| 识别 | `ddddocr`（ONNX，本机 Python 3.12）盯图，识别结果写进 `captcha-answer.txt`，流程每秒轮询该文件 |
| 抓图健壮性 | 上一轮提交后页面还在换图，直接抓会拿到空白占位图 → 循环重抓直到 PNG > 4000 字节（最多 15 轮） |
| 免打扰 | 识别脚本只读写文件，不碰窗口；窗口被 `--lg-userdata` 隔离，与正在使用的实例互不干扰 |

实测：9 个账号分两批全部入库（第一批 5/9，早期 4 个因人工介入太慢超时；补跑 4/4 全过，
每个账号从出图到通过约 10–20 秒，`ddddocr` 识别与人工读数逐张一致）。

### 切换时的会话探测（v3.2.0 加固）

切换账号前先探测目标分区是否还登录着（`probeSessionUser`）：拿到 uid 就直接换分区，
不用再走登录、不用再过验证码。但探测本身会因页面加载抖动假阴性 —— 假阴性会把一个
**本来登录着**的账号拖去重新登录（要过验证码），代价太高。所以：

- 页面内轮询读 4 次（每次隔 1.2s），导航区渲染慢不会被当成"未登录"
- `loadURL` 失败重试 4 轮
- 切换时若第一次探测为空，再探一次才认定失效

实测 `--lg-switchtest` 对全部 10 个账号：加固前两次各 9/10（每次挂的账号还不一样，
说明是抖动不是失效），加固后 **10/10**。

### 为什么用户检测要改

洛谷新一代前端（代号 lentille / columba）**移除了 `window._feInjection`**。现在改成 DOM 探测：从 `img[src*="usericon"]` 提取 UID 与头像，从页面文本匹配「欢迎回来，<用户名>」。本版还修了一个正则 bug：原表达式会吃掉用户名前几个字符（`u0lkd18fdr` 被截成 `18fdr`）。

### 注入流水线

每次标签页 `did-finish-load`：

1. **嗅探**：在注入 CSS 之前读页面真实底色 → `window.__lgNativeTheme`（避免采到自己写上去的半透明玻璃造成循环误判）
2. `insertCSS(INJECT_CSS)`
3. `executeJavaScript(INJECT_JS)` → 挂上 `window.__lgGlass`
4. `apply(cfgForPages())` → 把配置 + 算好的预设色一起以内联 CSS 变量写到 `<html>`

**单一事实来源**：所有视觉参数（tint / ink / border / accent / 圆角 / 壁纸 / 去色 / 边框强度）都由 `apply()` 以 `--lg-*` 变量下发，样式表只消费变量。设置页改任意一项都实时重涂，不用刷新。

### 页面 ↔ 应用的自定义协议

站内页面没有 IPC 通道（`contextIsolation` 开着，站点页不加载 preload）。从页面触发应用动作用的是一段自定义协议：

```js
window.open("luogu-glass://drawer/toggle")   // 开关分屏编辑器
window.open("luogu-glass://ide")             // 打开 IDE 标签页
```

主进程在 `will-navigate` 与 `setWindowOpenHandler` 两处拦截 `luogu-glass://`，阻止真实导航并执行对应动作。

## 八、已知限制（诚实说明）

1. **列表页筛选依赖 DOM 启发式**。洛谷列表结构改动后工具条可能抓不到行（此时不注入，不报错）。判定方式是"同一父节点下同类兄弟 ≥ 5 个"或表格 `tbody tr`。
2. **分屏编辑器不会自动把代码带进 IDE**。洛谷 IDE 没有开放"按题目号预填代码"的 URL 参数，代码靠手写；旁边给了「复制全部样例」。
3. **暗色模式仍是"整页反转"**。3.1.0 重做的是**上色逻辑**（主题色种子），深色本身依旧靠 `invert(1) hue-rotate(180deg)` 覆盖洛谷自带样式里没逐条接管的部分——这是取舍：不反转就得把洛谷几千条颜色规则一条条覆盖掉，漏一条就是白底黑字贴在深色页上。副作用：少数带背景图的元素会被一起反色（图片、视频、canvas、Monaco 已单独还原）。
4. **逆天改运只在"今日已打卡"之后可见**。洛谷的运势节点 `.lg-punch-result` 在打卡前根本不存在于 DOM（已用探针确认），所以没打卡时该项无事可做，打完卡会被 2.5s 轮询改写。
5. **Wallpaper Engine 的 Scene 类型壁纸只能用预览图**。`scene.pkg` 依赖 WE 自己的渲染引擎，浏览器里还原不了；视频类型（mp4/webm）可以真正播放。
6. **账号密码明文落盘**（见 §5）。
7. **界面缩放只作用于外壳**。放大外壳不会同步通知主进程改页面视图边距，缩放比例较大时页面区与工具栏之间可能有轻微错位。默认 100% 无此问题。
8. **难度徽章灰阶用的是宽松选择器**（`[class*="difficulty"]` 等）。若洛谷改了类名，该项会静默失效（不影响其它功能）。
9. **硬杀进程会弄脏 cookie 库**（`taskkill /F`、超时强杀），导致下次启动洛谷会话被重置。正常关闭窗口不受影响。
10. **下载不做"另存为"弹窗**，统一收进 `<下载>\Luogu++\`，靠面板里的「打开」定位。这是刻意选择（避免每个小文件都弹一次窗）。
11. 早先用户消息里有一句被截断的「同时我希望 c b」，一直没确认具体指什么，未做处理。

### 关于参考项目 O2-luogu 的核查结论（诚实记录）

用户要求参考 <https://github.com/TLEWA/O2-luogu>。该仓库是 **Stylus 用户样式「氧洛谷」**
（发布在 userstyles.world/style/18339，GPL-3.0，主文件 `O2luogu-userstyle.styl`），
`configs/Default.json` 里有 **401 个配置键，全部是 CSS 变量**（`Card-L1-radius`、
`Code-block-keyword-color`、`Topic-difficulty-Label-1..8`、`Font-Stack`、`SideBar-position` 等）。

- **它强而我们曾经缺**：细粒度视觉可调 → R13~R14 已补上配色预设 + 七个细调项。
- **它没有而我们强**：应用外壳、多标签、账号体系、列表工具条、分屏编辑器、书签/历史/下载。
- **没有照搬的部分及原因**：本产品视觉规范是黑白单色线条风，而 O2 的 401 个变量里很大一部分是彩色主题色（代码高亮、难度色阶）。实测洛谷新前端代码块不含任何语法 token 元素（`--lg-dump-tokens` 探针为证），没有可着色的目标；难度色阶则提供灰阶化开关而不是照抄 8 色。

## 十、快速上手

1. 双击 `D:\workspace\luogu++\app\LuoguLab.exe`
2. 首次启动是「原色」模式 —— 洛谷长什么样就什么样，只是顶栏换成了应用的
3. 按 `F2` 打开设置，按分组过一遍：
   - **页面美化**：想让它变成黑白线条风 → 页面配色切「亮色」；挑一套配色预设（推荐先试「宣纸」）；
     下面的「视觉细节」里调圆角、透明度、边框强度
   - **布局**：垂直标签栏默认开着，不习惯就关掉回顶部标签条
   - **功能**：所有开关可单独关
   - **账号**：填一次账号密码，验证通过后以后就在顶栏头像那里一键切
   - **地址栏**：想直达某个常用站点，添加映射（如 `deepseek` → `https://chat.deepseek.com`）
4. 记不住快捷键就按 `F1`；想找功能就按 `Ctrl+Shift+P` 敲命令面板
5. 看到好代码想拿走：鼠标移到代码块，右上角点「复制」
